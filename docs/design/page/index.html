A를 부드럽게 다시 그렸어요

"전체적으로 너무 딱딱해 보인다"는 말씀에 맞춰 A의 19개 화면을 모두 고쳤어요. 화면마다 지금 앱, A 처음, A 부드럽게를 나란히 놓았어요.

이 정도 부드러움이 맞는지 봐 주세요. "더 부드럽게", "이 정도 좋아", "표는 예전이 나았어"처럼 말씀해 주시면 그대로 맞춰요. 마음에 드시면 다음은 앱에 실제로 적용하는 단계예요.

화면별 비교

화면을 누르면 크게 볼 수 있어요. 모든 시안은 같은 예시 데이터(목표 "단단한 한 해", 64칸 중 24칸 달성)예요.

확인받을 것

  • 설정에서 빠지는 꾸미기: 종이 색 다섯 가지는 화면 모드(자동·밝게·어둡게)로 바뀌어요. 포인트 컬러와 칸 모서리 설정은 없어져요. 종이 무늬(점·모눈·줄)는 그대로 둬요.
  • 명조체: 목표와 숫자에 네이버 마루 부리를 써요. 앱에 넣으면 약 2MB가 늘고, 출시 전에 라이선스를 확인해야 해요.
  • 완성 표시: 영역 하나를 다 채웠을 때의 작은 주홍 도장은 선택지로만 남겨 뒀어요. 예전에 도장은 빼기로 하셨기 때문이에요.

남은 순서

  1. 부드러움 정도를 확인받기.
  2. 여덟 영역 색 다시 뽑기. 지금 색 중 두 쌍이 서로 너무 가까워요.
  3. 앱에 적용하기. 표, 홈, 탭 막대, 부품, 색, 다크 모드 순서로요.
