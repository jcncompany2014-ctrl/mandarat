## Deviations from the proposals

- **A-2, where the order goes.** The order is on the spread **row** (left page and right page), not on the host `View` with `spread-tabs`.
  - On iOS, `RCTViewComponentView.updateAccessibilityElements` sets `accessibilityElements` to exactly the listed views.
  - On the host, that would hide everything not listed: the overlays, the snackbar and any non-`Modal` sheet.
  - The tab bar and the overlays are later siblings of the row, so they still come after both pages in tree order.
- **A-2, the id prop.** I used `id`, not `nativeID`. RN 0.85's `View` maps `id` to `nativeID`, while react-native-web warns on `nativeID` ("deprecated. Use id").
- **A-2, how it is typed.** The prop is passed as `{ experimental_accessibilityOrder } as ViewProps`. The RN typings this project resolves (`Libraries/…/ViewPropTypes.d.ts`) don't declare it yet; only `types_generated` does. The prop name and type are checked against `node_modules/react-native/Libraries/Components/View/ViewPropTypes.js:508`. It is a no-op on the web, because react-native-web's `View` picks only known props.
- **A-2, the feature flag (important).** In RN 0.85 the native side is gated by `ReactNativeFeatureFlags::enableAccessibilityOrder()`. That flag is `false` in the stable defaults and `true` only in the OSS experimental overrides. So on our build the prop does nothing yet.
  - What actually keeps the order today is Fabric's `RCTViewComponentView shouldGroupAccessibilityChildren → YES`: each page `View` is not flattened (it has a background and a `testID`), so VoiceOver reads its children as one group.
  - The device-QA line asks someone to verify this on a device.
- **A-7 wording.** I used the reviewer's wording. Paper's own hint reads `프로 안내를 열어요`. The lead may want to make the two match (that is an F-1 or catalog call).
- **R-5 #2 on the web.** I did not use a plain `nowrap`. In react-native-web, `numberOfLines={1}` already gives nowrap with an ellipsis, which would turn the value into "2時間…". The estimated step-down avoids that.
