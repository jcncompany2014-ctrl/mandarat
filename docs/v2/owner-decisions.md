# v2 업그레이드 — owner 결정 (2026-10-17)

owner가 정한 것. plan과 다르면 이 파일이 이긴다.

1. 범위: 제안한 업그레이드를 모두 한다 — 알림, 홈·잠금 화면 위젯, iCloud 동기화, 연도별 표·1년 회고,
   인쇄용 PDF, 집중 타이머 Live Activity, 단축어·Siri, 일본어·영어, 아이패드, 수익 모델,
   앱스토어 스크린샷 자동 생성, 기기 테스트 자동화, 오류 수집.
2. 동기화: **iCloud** (로그인 없음, 같은 Apple ID의 아이폰·아이패드끼리). 웹·안드로이드는 지금처럼 백업 파일로 옮긴다.
3. 수익: **무료 + 한 번 결제(프로)**. 지금 무료인 기능은 계속 무료 — 새로 더하는 꾸미기·보관 기능만 프로로 연다.
   가격과 상품 등록은 owner가 나중에 App Store Connect에서 한다.
   - **2026-11 변경:** 1.0은 **결제 없이** 낸다(owner, '무료로 풀기'). 프로 기능(종이 무늬, 위젯 무늬, 인쇄 크기 A3·A5·B5와
     영역별 페이지, 지난 표 다시 보기)을 모두 무료로 연다 — `src/lib/pro.ts`의 `STORE_OPEN = false`.
     1.0에서 무료로 푼 기능은 나중에도 무료 — 판매를 켤 때는 프로에 **새 기능**을 넣고 `STORE_OPEN`을 켠다(`docs/RELEASE_CHECKLIST.md` v2-4).
4. 언어: **한국어(기본) + 일본어 + 영어**.
5. 오류 수집: **Sentry 연결** (연결된 Sentry 계정에 mandarat 프로젝트).
   - **2026-11 변경:** 1.0은 **Sentry 없이** 낸다(owner). 코드에서 뺐고, 다시 켜는 법은 `docs/RELEASE_CHECKLIST.md` v2-3.
6. Expo SDK는 56에 머문다(AGENTS.md가 v56 문서를 가리킨다). SDK 업그레이드는 이번 범위가 아니다.
7. 디자인 방향은 그대로: 종이 수첩 / 인쇄된 만다라트 표, AI 같은 꾸밈(둥근 카드·배지·그라데이션·반짝이·이모지·알약 칩·꽃·도장) 금지.
8. **2026-11 출시 준비:** 앱스토어 이름은 **만다라트 플래너**(ja マンダラート プランナー, en Mandalart Planner) — '만다라트'는 이미 다른 앱이 쓴다.
   홈 화면 이름은 '만다라트' 그대로. 저작권자는 owner 개인 이름. 디자인은 `docs/design/mockups/a`(A 깨끗하게)를 앱에 적용한 뒤 출시한다.
