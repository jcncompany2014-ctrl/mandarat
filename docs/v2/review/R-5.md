### 3. ja 「プロを開く」 does not read as "unlock" — P1

ko 프로를 열다 ("open up Pro") is a natural Korean metaphor. Japanese 開く does not carry it:
- 「プロを開きました」 reads as "I opened (the screen) Pro".
- 「プロが開いています」 reads as "Pro is open (for business)".

On a purchase confirmation the meaning has to be exact. Use 使える / 利用 instead.

| `ja/pro.ts` `noteBought` | プロを開きました。ありがとうございます。 | プロが使えるようになりました。ありがとうございます。 |

| `ja/pro.ts` `listHead` | プロで開くもの | プロで使えるもの |
| `ja/pro.ts` `buy` | `${price}でプロを開く` | `${price}でプロを購入` |

## Code sites with a hard-coded ASCII separator (ja voice) — P2

i18n.md §4 says no ASCII `·` in Japanese lines. These separators are not in the catalogs, so ja shows ` · ` in each place below. Example: the template sheet area list, `docs/v2/review/R-5/ja-xa-template.png`.

| File:line | Text |
|---|---|
| `src/components/TemplateSheet.tsx:66` | `t.areas.map(…).join(' · ')` |
| `src/screens/TodayModes.tsx:251` | `` ` · ${lead.text}` `` (streak head 「3日 · 하루 물 2L」) |
| `src/screens/TodayModes.tsx:407`, `:656` | the standalone `·` between area and kind line |
| `src/components/TodayRow.tsx:356` | `` `${area} · ${m.sheet.rowWritten}` `` |
| `src/components/TodayRow.tsx:360` | the standalone `·` |
| `src/screens/Dashboard.tsx:164` | `` `${m.year.homePrompt} · ${m.year.homePromptAction}` `` |
| `src/screens/Stats.tsx:309` | `` ` · ${parts.month}` `` (also the reflection date line 「10/13(火) · よい」, `ja-xf-stats-3.png`) |

Proposal:
1. Add a key `core.dot` with these values:
   - ko `' · '`
   - ja `'・'`
   - en `' · '`
2. Use it at these sites.

For the TemplateSheet list, `editor.listSep` would make it a comma list instead. `core.dot` keeps the look.
