## Deviations from the reviewers' proposals

- **R-8 #8 regex use.** The `CJK_RUN` match is replaced with `"…"`, the same token as quoted text, so a scrubbed string looks the same either way. It runs after the quote pass, so quoted text is still matched first. A Han/kana/Hangul run takes the rest of its **line**, not the rest of the message, so stack frames on later lines survive. This is what the reviewer's regex does with `[^\n]*`.
- **R-8 #7 `proSheet.test.js`.** Its regex (`:201`) checks `scripts/smoke/pro.js`'s own `owned` flag, not `pro.ts`. The web smoke never sets `EXPO_PUBLIC_APP_ENV`, so `/EXPO_PUBLIC_PRO_PREVIEW === '1'/` still describes the smoke correctly, and the file is unchanged. The `pro.ts` regex lives in `tests/pro.test.js`, which is updated. See handoff 3.
- **R-8 #7 release-check.** It fails when the variable is **present at all** (even `''` or `'0'`), not only when it is `'1'`. The value has no use in a release shell.
- **R3-1 file type.** The pbxproj file reference uses `lastKnownFileType = text.xml`, which is what Xcode uses for `.xcprivacy`.
- **R-8 #1 plan.md.** Besides the projectId line, the §1.2 App Privacy line is also updated (same list), so the owner checklist does not contradict the release checklist.
