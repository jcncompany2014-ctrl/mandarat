## Deviations

1. **`store.config.json` ko `releaseNotes`.** R-5 lists only the description. The What's New text had the same 아이폰과 아이패드 / 아이패드에서도, so I changed it to iPhone·iPad / iPad에서도 to keep the two fields consistent.
2. **`settings.colFont` ja.** The value "Pretendard · SIL OFL 1.1" is a literal in `Settings.tsx:392`, which I do not own. I added `settings.colFontValue` to the catalog instead:
   - ko and en: `Pretendard · SIL OFL 1.1`;
   - ja: `Pretendard・SIL OFL 1.1、和文はシステムの書体`.

   The ja value uses `・` rather than the reviewer's ASCII ` · `, per the ja voice rule (i18n.md §4: no ASCII `·` in Japanese strings). The wiring is Handoff 1.
3. **Tests that pinned the old strings on purpose.** I changed each one to pin the new value. None was weakened:
   - `tests/kinds.i18n.test.js`: ja/en `daysLong`, en `weekPlan`;
   - `tests/i18n-editor.test.js`: `perWeek`;
   - `tests/i18n-ritual.test.js`: `deltaLess`, `nextHint`;
   - `tests/i18n-stats.test.js`: ko `legendTimes` is pinned as "the same as before extraction", now `5+일` with a comment saying why; also ja `barTodaySay` / `habitMissed` and en `barFutureSay`;
   - `tests/printSheet.test.js`: `64マス中\d+マス達成`;
   - `tests/storeMetadata.test.js`: the en feature word is now `The year in review`;
   - `tests/dx-1-today.test.js` D-11: the standalone dot is `{m.core.dot.trim()}`, and the area name now has `flexShrink: 0, maxWidth: 78`.
4. **New test** `tests/f-1-copy.test.js` (8 tests):
   - `core.dot` values, and that the R-5 sites use it and contain no hand-written ` · `;
   - the ja/en day lists and `Nx a week`;
